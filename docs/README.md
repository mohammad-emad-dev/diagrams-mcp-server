ENGINEERING DOCUMENTATION
=========================

Use this index to choose the document for the work in front of you
The root README explains installation and tool behavior
The guides below cover ownership and contribution and release operations


CURRENT GUIDANCE
================

Read the [project README](%2E%2E/README%2Emd) for setup and configuration and the
fifteen tool contracts
Use [architecture](architecture%2Emd) to locate module responsibilities and
follow a request from the MCP adapter into its owning service

Before changing code read the [contribution guide](%2E%2E/CONTRIBUTING%2Emd)
It describes development prerequisites and validation and tool extension work
Use the [roadmap](roadmap%2Emd) to distinguish completed work from future candidates
Unreleased work on main becomes available through npm only after publication

For a release follow the [release checklist](release-checklist%2Emd)
It separates candidate verification from packaged acceptance and publication
If publication completes only partly consult [release recovery](release-recovery%2Emd)
Use [release notes](%2E%2E/RELEASE_NOTES%2Emd) to compare versioned behavior
