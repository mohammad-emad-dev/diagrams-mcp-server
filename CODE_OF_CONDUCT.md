# Code of Conduct

This project runs on one expectation: treat other people with respect.

## Respectful behavior

- Assume good intent and disagree about the work, not the person.
- Accept that the maintainer may decline an idea that does not fit the project.
- Write clearly and patiently; not everyone shares your background.

## Unacceptable behavior

- Harassment, insults, threats, or personal attacks in any form.
- Publishing someone else's private information without permission.
- Spam, advertising, or using issues and pull requests for anything but the project.
- Deliberately submitting harmful code or trying to bypass the security boundaries described in CONTRIBUTING.md.

## Enforcement

The maintainer may remove offending content and block accounts that violate this policy. Decisions here are final.

To report a problem, contact the maintainer privately through GitHub rather than opening a public issue. For anything sensitive, a private security advisory on the repository works.
